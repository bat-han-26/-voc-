# 올레샷(올리브오일+레몬즙 샷) 시장 · VOC 리서치 브리프

> 작성: 웹 검색 기반(2026) · 출처 링크 명시 · **매출액은 비공개라 대용 지표로 추정** · 정밀 수치/리뷰 전수는 크롤 단계에서 확보

## 1. 올레샷이란
- **올리브오일 + 레몬즙(대표 비율 7:3, 약 15ml)을 아침 공복에 '샷'처럼 마시는** 웰니스 루틴/건기식.
- 아이브 **장원영**이 마신다고 알려지며 2025~2026 급부상 → 건기식·푸드 카테고리로 빠르게 상품화(스틱 파우치 형태 다수).
- 소구 포인트: 폴리페놀·비타민E·비타민C, 저속노화/식단균형, 간편 스틱.

## 3. "Top 3" — 잠정(대용 지표 기준), 확정은 크롤 후
공식 매출 순위 데이터가 없으므로, **노출 빈도·판매 채널 다양성·검색 가시성** 기준의 **잠정 후보**:
1. **올레톡스** — 올레샷 키워드 검색 상위·브랜드 인지도 높음
2. **퓨어데이즈** — 쿠팡 중심 노출, '유기농' 포지션
3. **올리바즈모** — 다채널(11번가·오아시스·홈앤쇼핑) 노출 폭 넓음

⚠ 이 순위는 **검색 가시성 기반 추정**이며 실제 판매량/매출 순위가 아님. 확정하려면 채널별 **리뷰 수·랭킹·평점**을 크롤해 비교해야 함(아래 4번).

## 4. 매출액 현실 + 대용 지표
- **정확한 매출액 확보 불가**: 대부분 비상장 소규모 건기식 브랜드 → 공시·제품단위 매출 비공개. (지어내지 않음)
- **대용 인기지표(크롤로 확보 가능)**:
  - 채널별 **리뷰 수**(쿠팡/네이버/올리브영) — 판매량 비례 프록시로 가장 유용
  - **평점·평점분포**, 랭킹 노출 순위
  - 검색량 트렌드(네이버 데이터랩), 와디즈 펀딩액(해당 시)
- 진짜 매출이 필요하면 닐슨/와이즈앱·아이지에이웍스 등 **유료 데이터** 또는 내부/제휴 데이터 필요.

## 5. VOC 수집 계획 (채널별)
| 채널 | 적합성 | 수집 방법 |
|------|--------|-----------|
| **쿠팡** | ★ 올레샷 판매·리뷰 가장 많음 | 상품별 리뷰 API/페이지 크롤 (쿠팡용 수집기 신규) |
| **네이버 스마트스토어/쇼핑** | ★ 브랜드 자사몰 다수 | 스토어 리뷰 크롤 |

→ 수집 후 표준 스키마 CSV → `build_voc_dashboard.py`로 **동일 포맷 VOC 대시보드** 생성(브랜드 비교 + 제품별 전략 브리프).

## 6. 다음 단계 제안
1. **Top 3 브랜드 확정** (위 후보 또는 지정) + **분석 채널 1개 선택**(쿠팡 권장)
2. 해당 브랜드 제품 URL/상품번호 수집 → `config/olleshot_products.json` 작성(니즈 사전: 맛/풍미·공복섭취·간편스틱·효과체감·산도/품질·가격 등)
3. 채널 수집기로 리뷰 크롤(로컬) → CSV → 대시보드 생성
4. 대용 인기지표(리뷰 수·평점)로 **브랜드 순위 + 매출 프록시** 제시

> 참고: 크롤은 이 클라우드 환경에서 차단(allowlist)되어 로컬 실행 필요. CSV만 주시면 분석·대시보드는 제가 완성합니다.
